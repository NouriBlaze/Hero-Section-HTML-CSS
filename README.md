# Hero-Section-HTML-CSS
  A small practice project built while learning on Scrimba. It features a hero section with a background image, a heading, and a call-to-action button, all styled with plain HTML and CSS.
## What I Practiced
- Background image and hero image styling
- Margin and padding for spacing
- Text shadow on the heading
- Borders and border radius on the button
- Basic layout and positioning

## Tech Used
- HTML5
- CSS3
